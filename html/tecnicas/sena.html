Programación de Software

Convenio SENA - Formando el futuro tecnológico

Descripción

Somos una media técnica en convenio con el SENA, especializada en la programación de software. Aquí los estudiantes adquieren bases sólidas en programación y tecnología, preparándose para los desafíos del mundo digital actual.

Nuestro enfoque práctico permite a los estudiantes crear soluciones reales desde el primer día, fomentando el pensamiento lógico y la creatividad.

Lo que aprenderás

  • Lógica de programación y algoritmos
  • HTML, CSS y JavaScript para desarrollo web
  • Desarrollo de aplicaciones básicas
  • Gestión de bases de datos
  • Trabajo colaborativo y metodologías ágiles
  • Inglés técnico para el sector software
