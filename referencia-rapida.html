⚡ REFERENCIA RÁPIDA

Atajos y respuestas rápidas - Portal Institucional

🏠 ACCEDER A INICIO

Para ver noticias, eventos, historia y deportes.

Paso: Haz clic en INICIO en el menú superior

📍 VER SEDES

Para conocer nuestras 5 ubicaciones educativas.

Paso: Menú → SEDES → Selecciona una → Ver Sede

📊 MIS CALIFICACIONES

Para ver notas y desempeño académico.

Paso: ACADÉMICO → Sistema estudiante → Usuario/Contraseña

⚙️ PROGRAMAS TÉCNICOS

Para explorar las 5 opciones técnicas disponibles.

Paso: MEDIAS TÉCNICAS → Selecciona programa → Ver Programa

📖 HISTORIA DE LA INSTITUCIÓN

Para conocer 67+ años de trayectoria.

Paso: INICIO → Historia → Lee historia institucional

☎️ CONTACTO

Para comunicarte con la institución.

Paso: DEPARTAMENTOS → Teléfono o email de contacto

🔍 AUMENTAR LETRA

Para mejorar legibilidad del contenido.

Paso: Botón azul (♿) abajo derecha → Aumentar tamaño

🖨️ IMPRIMIR PÁGINA

Para guardar o imprimir información.

Ctrl+P (o Cmd+P en Mac)

🔍 BUSCAR EN PÁGINA

Para encontrar palabras en la página actual.

Ctrl+F (o Cmd+F en Mac)

🔄 ACTUALIZAR PÁGINA

Si algo no carga correctamente.

F5 o Ctrl+R

❌ CREDENCIALES OLVIDADAS

Si olvidaste usuario o contraseña.

Paso: Contacta coordinación académica de tu sede

📱 EN CELULAR

El portal funciona perfectamente en móvil.

Nota: La interfaz se adapta automáticamente

ℹ️ MÁS INFORMACIÓN

Para aprender más sobre el portal.

Abre: MANUALES.html (guías completas)

🆘 NO FUNCIONA ALGO

Si encuentras un error o problema.

Paso: Actualiza (F5) o intenta otro navegador
